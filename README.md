## What I'm building

### myJob — AI-powered Job Coach

An AI-native job search and application platform that turns the entire job-search workflow into a conversation.

Instead of manually searching job boards, evaluating positions, adapting CVs and writing applications, users tell myJob about their experience, goals and preferences. The system uses this context throughout the application process.

**What it does**
- Searches and evaluates jobs based on the user's profile
- Analyses job fit and explains strengths and gaps
- Generates tailored CV content and cover letters
- Tracks applications and avoids duplicate job records
- Integrates external job sources and application workflows
- Uses AI agents and tools to automate multi-step tasks

**Built with:** PHP · Laravel · MySQL · JavaScript · LLM APIs · REST APIs

### Recruiter Chatbot — AI Portfolio Assistant

A conversational AI assistant that allows recruiters to explore my professional background through dialogue instead of reading a traditional portfolio.

The assistant combines a structured knowledge base with LLM-based conversation to answer questions about experience, skills, projects and product decisions.

**Focus:** Conversational AI · Knowledge grounding · Prompt design · LLM APIs · UX


### Talk-to-onOffice — Voice-first CRM Concept

A concept for interacting with a real-estate CRM through natural voice conversations — designed for situations where traditional interfaces are impractical, such as while driving.

Users could ask about appointments, emails, contacts or property enquiries and perform common CRM tasks conversationally.

**Focus:** Voice AI · Conversational UX · CRM workflows · AI agents
